مختبر قوائم Python — واجهة تعليمية عربية

التشغيل:
1) فك ضغط الملف ZIP.
2) افتح المجلد في Visual Studio Code عبر File > Open Folder.
3) افتح index.html مباشرة في المتصفح أو عبر إضافة Live Server.

كل HTML و CSS و JavaScript موجود في index.html فقط.
يعمل الموقع بلا اتصال بالإنترنت ولا يحتاج إلى تثبيت مكتبات.

مهم:
- تمارين الموقع تعلمية إضافية عن Python Lists. ملف BY10 الأصلي يتناول المتغيرات والنصوص وأنواع البيانات ولا يحتوي فصل Lists.
- زر فحص الكود يتحقق نصيًا من عناصر أولية، ولا يشغّل بايثون فعليًا. شغّل الأمثلة في Python داخل VS Code للتحقق.
- يمكن نسخ الأكواد وتتبع التقدم محليًا في المتصفح.
